### Added

- Initial capability-aware MCP server and safe warning-light change workflow.
- Read-only detection, event, health, media, image, storage, and audio tools.
- Sanitized fixtures for supported DS-2CD2346G2-ISU/SL firmware versions.
- Generic example aliases and credential-variable names with read-only defaults.
- Automatic/configurable channel selection and model/firmware adapter registry.
- Support-aware detection reads that preserve configurations when optional sub-resources are
  unavailable.
